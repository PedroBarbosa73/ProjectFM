- Press 'P' to read positions and roles
- Press 'Space' to pause/resume the game

## 6. Substitutions
Format: "swap S[number] with [position]"
Example: "swap S6 with center midfielder"

Available position names:
- Goalkeeper: "goalkeeper", "keeper", "goalie"
- Defenders: "right defender", "right back", "right center defender", "center defender", "left center defender", "left defender"
- Midfielders: "right center midfielder", "center midfielder", "left center midfielder"
- Attacking Midfielders: "right attacking midfielder", "right winger", "left attacking midfielder", "left winger"
- Forwards: "striker", "forward", "center forward", "target man"

Examples:
- "swap S2 with goalkeeper"
- "swap S1 with right attacking midfielder"
- "swap S3 with striker"
- "swap S4 with center midfielder"

## Command Combinations
You can combine multiple commands in a single voice input. Examples:
- "high press and pass into space"
- "encourage and be more expressive"
- "change 5 12 and balanced"
- "low block and much lower defensive line"

## Command Execution Priority
Commands are executed in the following order:
1. Mentalities
2. Shouts
3. Instructions
4. Substitutions
5. Defensive Shape

## Tips
- Speak clearly and at a normal pace
- Hold Caps Lock while speaking
- Wait for the "Speak your command..." prompt
- Multiple commands can be combined with "and"
- The program will automatically handle menu navigation

## Troubleshooting
If a command doesn't work:
1. Make sure the game window is active
2. Check if the command is in the correct format
3. Try speaking more clearly
4. Wait a moment before giving the next command
5. Make sure you're holding CAPS LOCK while speaking
