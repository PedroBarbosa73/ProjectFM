Major Improvements in Current Version:
1. Completely Redesigned Defensive Line Movement System:
   * Replaced multiple drag attempts with a single, smooth drag movement
   * Implemented dynamic drag distance calculation based on target position
   * Standardized movement speed (20 pixels per position)
   * Unified timing (0.5 seconds per position) for both upward and downward movements
   * Removed unnecessary clicking after drag movements
   * Improved position verification system

2. Optimized Position Detection:
   * Reduced wait times for position checks
   * Improved confidence level handling
   * Faster position verification
   * More accurate position detection

3. Command Processing Improvements:
   * Better handling of "much lower" command
   * Improved command priority system
   * Enhanced error handling and logging
   * More efficient command splitting

Command Modes:
1. Text Mode:
   - Press 'T' to enter text command mode
   - Type commands directly
   - Type 'exit' to leave text mode
   - Use commas (,) to separate multiple commands
   - Example: "defensive, demand more, pass into space"

2. Voice Mode:
   - Hold Caps Lock to activate
   - Speak commands
   - Release Caps Lock to execute
